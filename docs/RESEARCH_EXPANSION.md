# Research expansion

The Atlas grows through versioned slices, not an undifferentiated stream of
solver output.

## Next research programs

1. **Scalene parameter space.** Normalize scale, sample two independent angles,
   publish the sampling lattice, and separate observed phase boundaries from
   verified records.
2. **Other containers.** Add polygons and curved boundaries only after the
   verifier gains an explicit versioned container contract.
3. **Finite versus asymptotic packing.** Record finite boundary loss separately
   from periodic interior density and attach the limit argument when known.
4. **Rigorous upper bounds.** Add bound objects with machine-checkable inputs,
   method names, tolerance policy, and human-reviewed proof references.
5. **Distributed solver runs.** Use immutable challenge manifests, deterministic
   seeds, resource metadata, and independent replay before accepting records.
6. **Literature ingestion.** Prefer primary publications, record page/figure
   provenance, preserve original parameterization, and never silently convert a
   published claim into a proof claim.
7. **Academic and classroom partnerships.** Publish beginner-sized reproduction
   challenges alongside research-frontier regions.

## Release cadence

Each dataset release receives a semantic version, changelog, generated snapshot,
verification report, license, contributor list, and—when appropriate—an
archival DOI. Corrections never rewrite an old snapshot; they create a new
release and link the disputed record’s history.
